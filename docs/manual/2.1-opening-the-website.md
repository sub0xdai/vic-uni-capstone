# 2.1 Opening the website

ContentCraft runs in a web browser.
There is nothing to install and no file to download.

## Before you start

- A computer with a current browser: Chrome, Edge, Firefox or Safari.
- An internet connection.
- JavaScript and cookies switched on. They are on by default in all four browsers. Switch them back on if you have turned them off.
- An email address you can open. The first time you use the site you create an account with it, and section 3.1 explains how.

## The address

https://aicontentpro-zeta.vercel.app

Type it exactly as it is written here.

## Steps

1. Open your browser.
2. Click the address bar at the top of the window.
3. Type the address above.
4. Press Enter. On a Mac, press Return.
5. Wait for the home page. It shows the AIContentPro logo and name at the top left, a headline that reads Turn Your Ideas into Powerful Content with AI, a get started button, and an example of the app further down the page.
6. Look for the padlock to the left of the address. The padlock means your connection to the site is encrypted, and the address begins with https.
7. To come back later without typing the address again, bookmark the page. Press Ctrl and D on Windows, or Command and D on a Mac.

You are now on the site.
To create an account or to sign in, use the Login or Sign Up button at the top right of the page.
Section 3.1 explains that form.

## If the page does not open

- Check your internet connection by opening any other website.
- Compare the address with the one in this section, character by character. Never add a space at the end.
- If the browser says cookies are blocked, allow cookies for this site and load the page again.
- If the page appears blank or the buttons do nothing, JavaScript is switched off. Switch it on and load the page again.
- If the browser says the site cannot be reached, the address has a typing error or you are offline.
- If none of that helps, try a second browser. That tells you whether the problem is the site or a setting in the first browser.
- If the site loads but signing in fails, the database behind it may be asleep. The site uses a free Supabase plan that pauses when it has not been used for a week. Tell the team, and they wake it from the Supabase dashboard.

**The deployment behind the address.**

- Hosted on Vercel, project `aicontentpro`, with the root directory set to `web`. Every push to `master` builds automatically.
- No repository file configures the deployment. There is no `vercel.json`, so the root directory, the build command and the variables all live in the Vercel project settings, which is why this note exists.
- No DNS work is needed. The address uses the free `*.vercel.app` domain, which Vercel issues. A custom domain would be a Vercel dashboard step plus a CNAME record, and a change to this section.
- The URL above is the short production alias. `aicontentpro-sub0x-projects.vercel.app` is the same site.
- Opening the bare address serves the public home page, and a visitor who is already signed in is sent to `/dashboard` from it. The Log in screen sits at `/login`, which is where the Login and Sign Up buttons lead, so screenshot 2.1.1 shows the short address and section 3.1 starts one click later.
- The two `NEXT_PUBLIC_*` Supabase values were inlined at build time, so the browser-side sign-in works. Both server routes answer a signed-out request with 401, which proves the database configuration resolved on the host.

**Two steps are still missing before this section is true for a new user.**

1. In Supabase, Authentication, URL Configuration, the Site URL and the redirect allow list still point at `localhost`. If email confirmation is switched on, a new account receives a link that goes to `http://localhost:3000` and never lands on the deployed site.
2. `CLOUDFLARE_ACCOUNT_ID` and `CLOUDFLARE_API_TOKEN` are not set on the deployment, so the AI Image Generator answers that image generation is not configured. Text generation is unaffected.

If the team moves to a custom domain later, one line of this section changes and screenshot 2.1.1 is retaken.
