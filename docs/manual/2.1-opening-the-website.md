# 2.1 Opening the website

ContentCraft runs in a web browser.
There is nothing to install and no file to download.

## Before you start

- A computer with a current browser: Chrome, Edge, Firefox or Safari.
- An internet connection.
- JavaScript and cookies switched on. They are on by default in all four browsers. Turn them back on if you have switched them off.
- An email address you can open. You need it the first time you use the site, to create your account. Section 3.1 covers that.

## The address

https://aicontentpro-zeta.vercel.app

Type it exactly as it is written. All the letters are small and there are no spaces.

## Steps

1. Open your browser.

2. Click the address bar at the top of the window.

3. Type the address above.

6. Look for the padlock to the left of the address. The padlock means your connection to the site is encrypted, and the address begins with https.

You are now on the site.
To create an account or sign in, use the Login or Sign Up button at the top right of the page.
Section 3.1 explains that form.

## If the page does not open

- Check your internet connection by opening any other website.
- Compare the address with the one in this section, character by character. Never add a space at the end.
- If the browser says cookies are blocked, allow cookies for this site and load the page again.
- If the page appears blank or the buttons do nothing, JavaScript is switched off. Switch it on and load the page again.
- If the browser says the site cannot be reached, the address has a typing error or you are offline.
- If none of that helps, try a second browser. That tells you whether the problem is the site or a setting in the first browser.
- If the site loads but signing in fails, the database behind it may be asleep. The site uses a free Supabase plan that pauses when it has not been used for a week. Tell the team, and they wake it from the Supabase dashboard.
